# Homebrew Tap

Custom Homebrew formulae by [Umut Çetinkaya](https://umutcetinkaya.com).

## Install

```bash
brew tap umutcetinkaya/tap
```

## Available Casks

| Cask | Description |
|------|-------------|
| `live-translator` | Real-time system audio translation for macOS |

```bash
brew install --cask live-translator
```
